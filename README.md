# Ticketing Platform

A backend for selling tickets to concerts, workshops and college fests.

## Goal

Organizers publish events and attendees buy tickets. The system must
**never oversell**: even if thousands of people try to buy the last 50
tickets at the same time, no more than 50 may be sold.

## Status

Early stage. Currently learning Python tooling and setting up the project.

## Tech (planned)

Python, FastAPI, PostgreSQL, Redis, Docker.

## Run it

    uv run ticketing
